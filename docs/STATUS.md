# Status: Episode 1 port (Rust/WASM + TypeScript)

Where the real game stands against `ENGINE_SPEC.md` and `GAME_DESIGN.md`. The behavioural reference is the prototype in `design/melting/` (kept untouched).

## Layout
| Path | Role |
|---|---|
| `crates/sim` | Engine core (Rust, game-agnostic): tile map with per-tile properties, AABB body, slopes, one-way and switchable tiles, moving platforms, instance buffer, light selection, event queue, RNG |
| `episodes/episode-1/game` | Episode 1 sim (Rust, cdylib to WASM): levels, player, enemies, boss, overworld, scene drawing, raw C-ABI exports |
| `packages/engine` | Engine shell (TypeScript): pixel DSL and atlas builder, Three.js instanced renderer, input, audio, fixed-step accumulator, WASM loader |
| `episodes/episode-1` | Episode 1 app: sprites, cinematic, DOM overlay, story text, saves, game flow, Vite entry |
| `site/` | The Fizz BBS website: front page (main menu and release log) and game guide, sharing one stylesheet; episodes listed in `site/episodes.json` |

## Run it
```sh
bun install
bun run dev            # builds the WASM, then Vite on http://localhost:5173 (add ?debug for window.__lf)
bun run dev:phone      # the dev server on the local network, with the addresses to open on a phone
bun run build          # WASM + production bundle in episodes/episode-1/dist (base /lieutenant-fizz/episode-1/)
bun run build:site     # landing page + episodes assembled in dist-site/ (what Pages publishes)
bun run validate       # format, lint, typecheck, vitest, clippy, cargo test, build
```
The WASM is built with plain `cargo build --target wasm32-unknown-unknown` and raw exports, so no wasm-bindgen CLI is needed. It is about 119 kB (48 kB gzipped), well inside the 2 MB target.

## Done and verified
Verified by `cargo test`, `vitest` (including the real WASM) and a real browser pass (Chromium via Playwright: no console errors, only the headless GPU perf notices).

- **Simulation (Rust, f64, 60 Hz fixed step):** run, variable-height jump, pogo (high bounce with jump held, about 6.6 tiles), fizz shots (aim up, aim down in the air, ammo), stomps, lives and extra lives every 100 points, snacks, keys and matching doors, switchable bridge, hover platforms that carry riders, spikes and chocolate, exit and level completion, deterministic given the same inputs. The ledge mantle is a 0.30 s timed pull-up (hang, rise, step over the lip) with three Ben frames rather than an instant move.
- **Enemies:** all eleven kinds ported (gloop, hopper, marshmallow, beetle, bat, spore pod, phantom, roller, sentry, drone, Cocoa Colossus with hover, globs, slam, charge and open-dome phases), plus the switch, terminal and caged Billy.
- **Overworld:** four regions (Crater Fields, Marshmallow Meadows, Rock Candy Reach, Frosting Frontier) cut by the rivers, each with its own ground and scatter sprites, a chocolate lake with an island at the centre, a small town (Crater Corners) of solid buildings and signposts east of the first level, teleporter pairs gated on sets of cleared levels, a locked Citadel point, and a hidden teleporter pad that appears once the secret mural has been found. Teleporters drop Ben on the partner pad's own tile, which is always ground. Saves are versioned (the save key never changes): a version 1 save keeps its progress but loses its map position, which belongs to the old layout. Map points are checked by flood fill: each region connects to the next only through its teleporter, and the island cannot be walked to.
- **Levels:** Crater Fields, Crystal Caves and Mildred's Citadel built by a port of the level builder, plus Meteor Mesa, the first open-sky level (a new tile set, drifting cloud layers and cloud-ledge platforms), Zarg Lookout, the first building level (ladders, stairs, a waiting lift, a tower camera), Marshmallow Meadows (a second open-sky level), Bonbon Playhouse, the first theatre level (hidden rooms behind fading painted flats) Fudge Bog (a harder crater) Mirror Shafts (a tall shaft of mirrors, a swivel mirror, crystal switches and three gates) the Sugar Glass Gallery (a long theatre with a secret mural room that records the secret-found bit), Frosting Flats (the hardest open-sky level, with hover chains) Frosting Spire (twelve floors, three lifts and the third key colour, green) the Cocoa Foundry (conveyor belts, crushing presses and molten metal) Whisper Hollow (a climbing cave: vine ropes, a wall-kick chimney, hanging vines and mantled shelves) and Ben's saucer (a walk-through with no goal, entered from the map); overworld with rivers, teleporter pairs that power up as levels are cleared, level prompts. Levels come from a `LEVELS` table (builder, theme, area, overworld icon) indexed by id, so a level's look is a `Theme` rather than its id. Map points carry a requirement mask: a teleporter or level point works only once every listed level is cleared.
- **Rendering:** one instanced draw call per frame; instance buffer is a zero-copy view over WASM memory; 2048 atlas with extruded borders and generated normal maps; Lambert lighting with up to 16 nearest-first point lights; day and night profiles; posterise, normals and culling toggles; 50k-tile stress mode; pixel-grid camera snapping; parallax layers per biome.
- **Shell:** title with attract mode, controls screen, eight-panel opening cinematic (drawn in TypeScript into the shared buffer), HUD, boss pips, map prompts, toasts, dialogue with typewriter text, pause menu, level-cleared, death and game-over cards, four-panel ending, skippable credits roll (with a paged reduced-motion form), floating sound captions, engine panel (backtick), zoom (wheel, `-`, `=`, `0`).
- **Input:** Keen-style and modern keyboard layouts, standard gamepad, edge detection per fixed tick in the sim. In menus a held direction repeats after 350 ms and then every 90 ms (keys, pad and the touch D-pad alike).
- **Audio:** `@liminal-hq/undertone` 0.2.0 plays all sound effects (one-shot stacks, including high-pass voices) and music (looped stacks at each track's BPM, with `room` and `delay` sends). The built-in mini-notation synth is kept only as a fallback, used when Undertone fails to load or throws while building or starting a sound. Audio unlocks on the first click or key press, and sound captions still trigger their effects. Tests cover the Undertone routing and the fallback against a mocked `AudioContext`. Audible output has not been checked, so mixing, loop timing and the fallback's sound are unverified.
- **Saves and options:** progress (lives, score, ammo, cleared levels, map position, time played) autosaves on every overworld visit into a read-only autosave, and four manual slots are written from the pause menu's Save game or with F5. Each slot shows a mini overworld, area, cleared pips, lives, score, time played and date. F9 and Continue load the newest save. Saves are version 3; versions 1 and 2 still load. Options (the sound style, music and effects meters and the Sound lab switch on the Options > Sound screen, captions, controls layout, text size, motion) are saved separately. Hints switch between keyboard, gamepad and touch labels with the last input used. A saved map position that lands on a river, tree or rock on the current map snaps back to the saucer.
- **Pages:** `.github/workflows/pages.yml` builds the WASM and Vite app and assembles the site; `ci.yml` runs format, lint, typecheck, vitest, clippy and cargo test. The site is styled as a dial-up BBS in the EGA palette; `e2e/site.spec.ts` checks both pages at 1280, 1000, 768, 390 and 320 px wide (whole-pixel Fizz sizes, no clipped text or sideways scroll, sprites, menus and links).

- **Credits and stinger:** the credits roll runs after the ending panels and before the score card (Esc or Start skips, Jump speeds up then continues). The stinger scene (silence, `stinger` low sting with a `♪ low sting` caption, slit of light into a doorway, `billyAlt` Mortimer sprite, typed line) is an engine capability configured per episode; Episode 1 sets `stinger: null` and `?previewStinger` shows it for review. Covered by unit tests for the sequencing and timing state machines and for the `stinger` audio pattern. Checked in Chromium with screenshots at 1000x615 and 390x700 (roll positions, hold, reduced-motion pages, stinger stages). The sting has not been heard and the gamepad path (Start and A) has not been tried on hardware.

- **Playtest bot:** `playtest.rs` (test-only) searches for a winning input sequence through the real simulation, branching worlds with `World::fork`. It removes hostile enemies, so a pass proves the platforming, keys, switches and exit work, not that the level is easy. Crater Fields, Crystal Caves, Meteor Mesa, Zarg Lookout (up to the roof key and back down), Marshmallow Meadows, Bonbon Playhouse, Fudge Bog, Mirror Shafts (which it solves by firing at the right moment, including the swivel's two-shot puzzle) the Sugar Glass Gallery (including its mural alcove), Frosting Flats, Frosting Spire (all three keys, up the tower and back down), Whisper Hollow (by vine, kick and mantle) and the Cocoa Foundry pass (the bot removes enemies, so press timing is tested separately); the Citadel's boss fight is not covered.
- **Title:** Ben stands on the wordmark, pogoes across it, faces the menu as the selection moves and waves when an item is picked. Attract mode pans a deterministic camera across Crater Fields, Crystal Caves and Mildred's Citadel with a fade between them and an "Attract · level" label; the camera never shows below the bottom tile row.
- **Layout checks:** `bun run test:e2e` drives Chromium at 1280×720, 1000×615, 1600×600 and 390×700 across the title, controls, options, saves, pause, cinematic, dialogue and credits screens: nothing overflows the window, clips or crowds the hint bar, and all pixel text is `11 × n` px in Fizz. It is not part of `validate` and needs a Chromium (`bunx playwright install chromium`, or `LF_CHROMIUM_PATH`).
- **Fizz pixel font in the overlay:** every overlay surface (HUD, menus, prompts, toasts, dialogue, letterbox, credits, stinger, engine panel, loading and errors) is set in Fizz at whole-pixel sizes chosen from the window height. Menus use the stepped plate and the soda bullet. The webfonts (Space Grotesk, Inter, JetBrains Mono) are gone.
- **Fizz pixel font:** the family (Regular, Bold, Oblique, Bold Oblique, Condensed, and Mono Regular and Bold) is generated from the glyph grids in `packages/engine/src/font` into OTF and WOFF2 files under `packages/engine/assets/fonts`, with Canadian French accents, box drawing, the 24 pictures and button and keycap glyphs. `bun run check:font` (part of `validate`) fails if the committed files are stale. See [FONT.md](FONT.md).

## Known gaps and deviations
- **Quick-save is progress-only.** The prototype serialised the whole simulation mid-level; the port saves progress at map granularity (F5 in a level saves progress, F9 returns to the map). Full mid-level snapshots need a serialisable world in Rust (planned).
- **Playability is only partly tested.** The playtest bot proves Crater Fields, Crystal Caves, Meteor Mesa, Zarg Lookout, Marshmallow Meadows, Bonbon Playhouse, Fudge Bog, Mirror Shafts, the Sugar Glass Gallery, Frosting Flats, Frosting Spire, the Cocoa Foundry and Whisper Hollow can be finished without enemies. No human has played them, difficulty tuning and secret areas are still open questions, and the boss fight is untested.
- **Overworld simulation** lives in the same Rust world, but its light is flat (no lighting), like the prototype.
- **Cinematic text** uses the prototype's eight panels, which `STORY.md` records in full.
- **New settings from the designs** (the Pixels option, which only has the `?pixels=sharp|soft` query for now, Scanlines, Screen shake, desktop window mode and rumble) are not built; see `docs/APP.md`.
- **Design-system tokens:** the overlay uses the Afterglow colours, scrims and panels as hard-coded values, not the Liminal HQ design-system tokens or components.
- **Sparse spatial grid / quadtree** for entity-entity tests is not built (O(n) per level, as in the prototype). Entities are cloned per tick; shots and effects still allocate, so the "no GC / no allocation in play" target is not met yet.
- **Cast shadows, WebGPU, Tauri shell, React overlay** from the spec are not started. The Tauri app and the React launcher are planned in `docs/APP.md`.
- **Gamepad** mapping is unit-tested but not exercised against real hardware.
- **Mobile** is partly built: the in-level touch controls (D-pad, Jump, Pogo, Fizz, Pause), the glass HUD pills, the phone viewport and safe areas, and the Rotate screen are in, and the pixel-perfect phone scale (a whole pixel scale on touch, with the leftover height showing more of the level), and the controls stay up on menu-style screens and drive them like a gamepad (D-pad, Select, Back, Pause; touch hints; menus laid out clear of the controls; single-tap rows, Options steppers and tap-to-advance text). The phone title is tidied (the one-column title is the default, with an opt-in split layout at `?title=split`); the Controls screen shows a touch column and a "← Back" button closes Controls, Options and Saves on a phone (and resumes from the pause menu), while the on-screen Pause button leaves the whole menu from any of them; the browser's Back button is the game's in fullscreen or an installed app, or with `?back` (`BackGuard`; dormant on a phone until slice 7 brings fullscreen); touch settings are stored (`lf-touch-v1`) and the Options > Touch controls screen sets Size, Opacity and Left-handed and Move controls opens a drag editor for the D-pad and buttons (each drop is saved; Reset puts the positions back); the haptics core (`navigator.vibrate` through `GameHaptics`: priorities, policies, a vibration budget and a cue for every caption or an explicit silence; feel unverified on a device) and controller rumble (`gamepad` backend, routed by the input device in use; unverified on real hardware) are in and on by default where a vibrator or a pad exists, with an Options > Haptics screen (Strength, Rumble, Haptics lab, Reset; the Haptics lab shares the Lab button with the sound lab and has Cues, Tune, Compare and Compile tabs; `?haptics` and `?haptics=off` override for a visit and show as "(link)" rows that cannot be changed, as `?audio=` does for Style and `?debug` for the lab rows); lifecycle is in progress: fullscreen and the landscape lock on the gesture that starts or resumes a run, and auto-pause when fullscreen ends (which is how Android Back pauses), are built in slice 7.1 (Auto is on for touch devices; `?fullscreen` and `?fullscreen=off` override; unverified on a device), and the wake lock, the manifest and icons and the Options > Display screen are planned in `docs/MOBILE_PLAN.md`.
- **Bundle:** three.js dominates (~590 kB minified); no code splitting.
