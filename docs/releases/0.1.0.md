**Lieutenant Fizz 0.1.0** is the first release of the player app: *Episode 1: The Cocoa Caper* as a desktop app for Linux and an Android app, built from the same Rust and WebGL game as the web version.

## Downloads

- **Linux** (x86_64 and aarch64): `.deb`, `.rpm` and AppImage. The packages are unsigned.
- **Android:** a signed universal APK (minSdk 26, landscape) and the signed AAB that goes to Google Play. The mapping file and the native debug symbols are attached for reading crash reports.
- **`SHA256SUMS`** covers every file. Check your download against it.

Windows and macOS builds and the Google Play listing come later.

## What is in it

- **The game:** all of Episode 1, from the opening cinematic to the ending, with saves, options and the Controls screen. In the app, saves and settings are kept in the app's own data file instead of the browser's storage.
- **Phone haptics:** the Android app plays the game's cues as vibration patterns through the phone's vibration motor, with a strength setting under Options > Haptics.
- **Controller rumble:** on Linux, PlayStation controllers (DualShock 3 and 4) rumble for the same cues, with a Rumble strength for each controller model.
- **Controller remapping:** Options > Controller lets a player bind one or more gamepad buttons to each action.
- **Android Back gesture:** the system Back gesture goes to the game as the Back button, and the screen underneath peeks through as the pause menu and the options screens slide away.
- **Quit and fullscreen:** the title and pause menus have Quit to launcher and Quit game rows, and `F` or `F11` takes the desktop window fullscreen.
- **Ben bumps his head:** a clunk plays when Ben jumps or pogoes into a ceiling.
- **Touch fixes:** on-screen button words fit inside their faces, and screen shake fades out in every mode.

## Known limits

- The Linux packages are not signed; Windows and macOS are not built yet.
- Controller rumble has been tried with a DualShock 3 and a DualShock 4 on Linux only. Xbox pads, DualSense, Windows and macOS are untried.
- On Linux, rumble needs write access to the controller's `/dev/input/event*` node, which a normal desktop session grants. A minimal install or a remote session may play no rumble.
- The launcher is a simple menu for now; the episode carousel and app settings are still to come.
- Most levels have been proved finishable by a playtest bot but not yet played through by people, and the boss fight is untested; difficulty tuning is still open.
- A set of phone-width browser tests is switched off while its flakiness is reviewed (see `docs/STATUS.md`).
