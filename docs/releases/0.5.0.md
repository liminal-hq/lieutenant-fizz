**Lieutenant Fizz 0.5.0** adds Normal and Expert modes, six keyboard control schemes with a mouse option, and a pogo that forgives a Jump press made a moment too early or too late. The DOS port of the same game reaches 0.5.0 with it, so the two share a version and the same rules.

## Downloads

- **Linux** (x86_64 and aarch64): `.deb`, `.rpm` and AppImage. The packages are unsigned.
- **macOS** (Apple silicon and Intel): one universal `.dmg`. It is not notarised, so macOS blocks the first open; see below.
- **Windows** (x64 and arm64): an `.msi` and a setup `.exe`. They are unsigned, so SmartScreen warns on first run; see below.
- **Android:** a signed universal APK (minSdk 26, landscape) and the signed AAB for Google Play. The mapping file and the native debug symbols are attached for reading crash reports.
- **`SHA256SUMS`** covers every file. Check your download against it.

The [getting-started guide](https://github.com/liminal-hq/lieutenant-fizz/blob/main/docs/GETTING_STARTED.md) has the steps for each system.

## What is new

- **Normal and Expert modes.** New game asks which to play, with Normal highlighted first. Normal is gentler: each 3- or 4-wide run of spikes is one tile narrower, and the Cocoa Foundry has six fewer enemies. Expert is the game as it was made. The mode is kept in every save and play sample, and saves from earlier versions load as Expert.
- **A pogo that forgives your timing.** The high pogo bounce used to need Jump held on the exact tick Ben landed, so a press a few frames early did nothing. A Jump press now counts if it comes up to 0.12 seconds before a landing, and a press up to 0.08 seconds after a low bounce turns it into the high one. Jumps without the pogo are unchanged.
- **Six keyboard control schemes**, chosen under Options › Controls. **Modern is the new default:** Z jumps, X works the pogo, C or Space fires Fizz, and the arrow keys or WASD move. The others are Keen-style (Ctrl, Alt and Space), WASD (Space, K and J), Mouse jump (the same, with the jump and Fizz swapped), Left hand (everything under the left hand) and Right hand (the arrow keys and the three keys beside them). Only the chosen scheme's keys act, and none but Keen-style uses a modifier key, so no browser or desktop shortcut gets in the way.
- **The mouse, in WASD and Mouse jump.** The right button works the pogo. The left button fires Fizz in WASD and jumps in Mouse jump, where holding it gives the high pogo bounce. The buttons act only on the game itself, so clicking a menu stays a click.
- **Key names match your keyboard.** The hints and the Controls screen name each key as it is printed on your keyboard, so an AZERTY keyboard reads Z, Q, S and D where a QWERTY one reads W, A, S and D. This needs a browser or app that can say what layout you have; elsewhere the names are the US ones.
- **Down grabs vines and ladders.** Pressing Down while standing on a ledge above a vine grabs it, and so does pressing Down while falling past a vine or ladder. Down with Fizz held still aims down and never grabs.
- **Short pad presses are no longer lost.** While a controller is connected the game reads it every 4 milliseconds, so a tap shorter than one game tick still counts.
- **An Input test page.** Options › Input test shows live what the game receives from a pad, keyboard, touch screen and mouse, to check a controller or see which action a key gives. Holding Esc for a second, or the pad's Back button, leaves it.
- **Smaller changes.** A hidden Debug menu opens from any screen with `2` then Enter and can warp to any level. A warped run never writes a save.

## Changed

- **Ctrl and Alt no longer play unless you choose Keen-style.** Before, Ctrl or Z, Alt or X and Space or C all worked at once. Now only the chosen scheme's keys act. If you played with Ctrl and Alt and never changed the setting, set Options › Controls to Keen-style to get them back. A choice you saved earlier is kept.

## Known limits

- The Linux, macOS and Windows builds are not signed by a publisher or notarised.
- Controller rumble has been tried with a DualShock 3 and a DualShock 4 on Linux only. It is untried on macOS, Windows, Xbox pads and DualSense, and the gamepad mapping has not been checked on real hardware beyond that.
- An Android device may crash when an Xbox 360 controller is plugged in over USB-C (#237). Haptics on macOS and Windows are not built yet (#238).
- The playtest bot has proved most levels can be finished, but the boss fight is untested by it, and difficulty tuning in both modes is still open.
