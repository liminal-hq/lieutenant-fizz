**Lieutenant Fizz 0.3.0** replaces the app's plain first menu with the launcher, a game-style screen with a carousel of episodes and app-wide settings, and makes the options and saves shared across episodes.

## Downloads

- **Linux** (x86_64 and aarch64): `.deb`, `.rpm` and AppImage. The packages are unsigned.
- **macOS** (Apple silicon and Intel): one universal `.dmg`. It is not notarised, so macOS blocks the first open; see below.
- **Windows** (x64 and arm64): an `.msi` and a setup `.exe`. They are unsigned, so SmartScreen warns on first run; see below.
- **Android:** a signed universal APK (minSdk 26, landscape) and the signed AAB for Google Play. The mapping file and the native debug symbols are attached for reading crash reports.
- **`SHA256SUMS`** covers every file. Check your download against it.

The [getting-started guide](https://github.com/liminal-hq/lieutenant-fizz/blob/main/docs/GETTING_STARTED.md) has the steps for each system.

## What is new

- **The launcher.** The app now opens on a game-style screen with the game's menu look, in the apps only (the website still opens the game's own title). A carousel steps between Episode 1 and App settings, with an arrow, a swipe, the keyboard or a pad. Episode 1 has Continue (with where it loads from), New game, Load game and Options; Continue and Load game appear once there are saves. Behind the menu each stop has its own scenery that drifts past at its own speed, with Ben running along it, grabbing treats, hopping onto gloops and stunning a far one with a fizz bubble. The launcher plays the menu sounds and buzzes as the game's menus do, plays each stop's music and crossfades between stops, shows the game's on-screen controls on a phone, and remembers which stop you left on. On the desktop it has a Quit row and fullscreen; on Android, Back leaves the app from the launcher.
- **App settings.** The last stop has Settings (Sound, Display and Controls tabs, each saving as you change it, with a two-tap Reset), Saves and About. About > Version, chosen seven times, shows the debug menu that the old first menu used to be.
- **Options for every episode or one.** The app-wide options now live in one shared options file. In the game, Options has an **Applies to** row: **All episodes** (the default each visit) or **This episode**, and a row that an episode overrides is marked with a `*`. An older build's saved options are carried over the first time.
- **Saves you can move.** App settings > Saves exports every episode's saves to one `.fizzsave` file and imports it back. An import checks the file before using it and merges slot by slot with the newest save winning, so an old file never replaces newer play.
- **Enhanced music and effects are what Auto plays.** In 0.2.0 both Sound rows started on Auto, which played the Classic originals. Auto now plays Enhanced, and Classic is one step away in Options > Sound. A choice you saved is kept as you made it. The launcher's title theme has an Enhanced song too.
- **A livelier overworld.** The map is lit by day with a sun and point lights, its trees and buildings stand up and draw back to front, shores, path edges and ground decals break up the grass, and every level has its own landmark with a flag for its state. Crater Corners now sits next to Zarg Lookout, and Ben returns to his level's doorstep when he comes back to the map.
- **Play samples and replays.** Recording a play sample (opt-in) now keeps exact event ticks, level entry state and the touch layout. In the apps, samples are kept in a SQLite database on disk, and can be saved or shared from the desktop and Android apps. A saved sample can be watched back in the game on the real simulation, and the developer viewer can open a sample zip from a file, watch it with hot spots, add comments, and export the run with notes.
- **Smaller changes.** The Android launcher icon is drawn smaller so it is no longer cropped, and the texture atlas packs its tallest sprites first.

## Known limits

- The launcher has been built and tried during development, but not yet on every system. The macOS and Windows installers have been built but not yet opened on a Mac or a Windows PC, and Android's file picker for importing saves has been checked on a phone but not by a test.
- The game redraws every frame at the display's rate, which costs more battery on a phone than it needs to; skipping unchanged frames and a 60 Hz cap for touch are planned (issue 216).
- The Linux, macOS and Windows builds are not signed by a publisher or notarised.
- Controller rumble has been tried with a DualShock 3 and a DualShock 4 on Linux only. It is untried on macOS, Windows, Xbox pads and DualSense.
- Most levels have been proved finishable by a playtest bot but not yet played through by people, and the boss fight is untested; difficulty tuning is still open.
- A set of phone-width browser tests is switched off while its flakiness is reviewed, and the browser jobs in the continuous-integration run still time out now and then (see `docs/STATUS.md`).
