**Lieutenant Fizz 0.1.1** adds macOS and Windows builds, and takes the Internet permission out of the Android app.

## Downloads

- **Linux** (x86_64 and aarch64): `.deb`, `.rpm` and AppImage. The packages are unsigned.
- **macOS** (Apple silicon and Intel): one universal `.dmg`. It is not notarised, so macOS blocks the first open; see below.
- **Windows** (x64 and arm64): an `.msi` and a setup `.exe`. They are unsigned, so SmartScreen warns on first run; see below.
- **Android:** a signed universal APK (minSdk 26, landscape) and the signed AAB for Google Play. The mapping file and the native debug symbols are attached for reading crash reports.
- **`SHA256SUMS`** covers every file. Check your download against it.

The [getting-started guide](https://github.com/liminal-hq/lieutenant-fizz/blob/main/docs/GETTING_STARTED.md) has the steps for each system.

## What is new

- **macOS:** a universal build, ad-hoc signed. To open it the first time, choose **Open Anyway** in System Settings > Privacy & Security, or run `xattr -dr com.apple.quarantine "/Applications/Lieutenant Fizz.app"` once.
- **Windows:** installers for x64 and arm64. On the SmartScreen warning, choose **More info**, then **Run anyway**.
- **Android:** the app no longer asks for the Internet permission. The game makes no network requests, so the only permission left is vibration.
- A privacy policy page and a getting-started guide.

## Known limits

- The Linux, macOS and Windows builds are not signed by a publisher or notarised.
- Controller rumble has been tried with a DualShock 3 and a DualShock 4 on Linux only. It is untried on macOS, Windows, Xbox pads and DualSense.
- The macOS and Windows installers have been built but not yet opened on a Mac or a Windows PC.
- The app opens on a simple menu first (Episode 1 and some test pages); the launcher is still to come.
- Most levels have been proved finishable by a playtest bot but not yet played through by people, and the boss fight is untested; difficulty tuning is still open.
- A set of phone-width browser tests is switched off while its flakiness is reviewed (see `docs/STATUS.md`).
