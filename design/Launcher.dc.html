Launcher · desktop

The same carousel as 2a, in a 16:9 window with a frameless title bar. Use it with the keyboard (click the window first): ↑↓ select, ← → change episode or value, Enter plays, Tab switches section, Esc goes back. Hovering the mouse selects a row, and a click chooses it. Desktop swaps the touch settings for its own. Haptics becomes controller Rumble. Display adds Window (windowed, fullscreen or borderless) and V-sync. Controls has keyboard layouts and shows the connected controller. App settings gets a Quit row.

Lieutenant Fizz · Android launcher · landscape · turn 2

Launcher · carousel with an app-settings stop

Builds on 1a. Each episode stop in the carousel stands in for that episode's own title screen, which the game skips when it loads from here. The fourth stop is App settings: global Settings, Saves (export and import every episode in one file), and About (tap Version seven times for the engine panel). Each episode's Options only change that episode, with a per-row "All episodes / Episode N" switch. Reset needs a second tap within three seconds. On an episode it clears that episode's overrides, and in App settings it restores every default.

Lieutenant Fizz · Android launcher · landscape · turn 1

Launcher · two ways to layer it

Both use the in-game menu language: a scrim over a live demo of the selected episode, stepped colour-cycling plates, and the soda can as cursor. 1a makes the launcher the episode's title screen, so you get one layer and go straight into play. 1b is a hub of episode cards that hands off to each episode's own title menu, so there are two layers with a way back. Settings are shared, and each row in Options can be set for one episode only (values marked * are overrides). Tap Version seven times to unlock the engine panel. Episodes 2 and 3 are mock-ups.
